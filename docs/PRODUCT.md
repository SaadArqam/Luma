# Product Overview

Luma is an AI-powered Personal Operating System that helps users understand their life through calm, intelligent interfaces. It combines expense tracking, goal management, task organization, and AI-powered insights into a unified experience.

## What is Luma?

Luma is not a finance app, a productivity tool, or a dashboard. It's a personal operating system—a single place where users can understand all aspects of their life: money, goals, tasks, and habits.

The core insight is that these domains are interconnected. Spending affects goals. Tasks relate to habits. Everything connects to the bigger picture of a person's life. Luma helps users see these connections and understand their life holistically.

## Target Users

Luma is designed for individuals who want to:

- Understand their financial patterns and spending habits
- Set and track meaningful life goals
- Organize tasks and priorities effectively
- See connections between different aspects of their life
- Use technology to reduce stress, not add to it

**Primary User Profile:**
- Ages 25-45
- Tech-savvy but not technical
- Values calm and clarity over features and complexity
- Wants to understand their life, not just track data
- Likely uses multiple apps for different purposes today

## Core Experiences

Luma is designed around three primary experiences:

### 1. Capture

The fastest way to add information to Luma. Users can quickly add expenses, goals, tasks, or notes from anywhere in the app using the quick add sheet.

**Key Features:**
- Quick add sheet accessible from any screen
- Smart defaults based on context
- Keyboard shortcuts for power users
- Voice input support (future)

### 2. Today

The primary landing experience. Today shows users what matters right now—upcoming tasks, spending insights, goal progress, and contextual information based on time and behavior.

**Key Features:**
- Daily overview of what matters
- Contextual information prioritized by AI
- Spending insights for today
- Task priorities and deadlines
- Goal progress updates
- Time-aware content (morning vs evening)

### 3. Timeline

A chronological view of everything—expenses, goals, tasks, and life events. Timeline helps users see patterns, understand progress, and reflect on their journey.

**Key Features:**
- Chronological view of all data
- Pattern recognition and insights
- Progress visualization
- Reflection prompts
- Historical comparisons

- Integrates with goals, tasks, and habits
- Focuses on patterns and insights, not just transactions
- Calm interface, not dashboard-heavy

## Technology

### Platform

- **Web Application:** Progressive Web App (PWA) with offline support
- **Responsive Design:** Optimized for mobile, works on desktop
- **Cross-Platform:** Works on iOS, Android, and desktop browsers

### Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript
- **Styling:** Tailwind CSS v4 with custom design tokens
- **Backend:** Supabase (PostgreSQL, Auth, Realtime)
- **State Management:** Zustand for client state, Server Components for server state
- **PWA:** Serwist for service worker and offline support
- **AI:** Groq SDK for AI-powered features

### Performance

- Fast load times with optimized assets
- Smooth animations at 60fps
- Efficient rendering with React Server Components
- Offline support with service worker caching
